AffectFlux 💙🌀

AffectFlux is a mood-tracking diary application built with Spring Boot and Java.
It allows users to log their daily mental “score” and visualize emotional trends over time through automatically generated graphs.

✨ Features

📖 Simple mood diary — record your daily mood score.

📊 Graph visualization — see fluctuations in your mood over time.

🔎 Insights — track patterns and gain awareness of emotional well-being.

🛠 Built with Spring Boot & Java, designed for extensibility.

🚀 Future Plans

User authentication and personalization.

Export/import mood data.

Notifications & reminders.
